# GitHub Profile Setup Guide

## 🚀 Quick Start - Activate Your Profile

Follow these steps to make everything work:

### Step 1: Commit and Push Changes

```bash
git add .
git commit -m "✨ Add crazy visual effects to GitHub profile with animations"
git push origin main
```

### Step 2: Enable GitHub Actions (If Not Already Enabled)

1. Go to your repository: `https://github.com/Ank0it/Ank0it`
2. Click on **Settings**
3. Click on **Actions** in the left sidebar
4. Under **Actions permissions**, select **Allow all actions and reusable workflows**
5. Click **Save**

### Step 3: Manually Trigger the Snake Animation

1. Go to the **Actions** tab in your repository
2. Click on **Generate Snake Animation** workflow in the left sidebar
3. Click **Run workflow** dropdown button
4. Click the green **Run workflow** button
5. Wait 1-2 minutes for the workflow to complete
6. Refresh your profile to see the snake animation!

### Step 4: Verify Everything Works

Visit your profile at `https://github.com/Ank0it` and check:

- ✅ Animated header with your name
- ✅ Typing animation showing your roles
- ✅ Profile view counter and follower badges
- ✅ Animated tech icons (8 rotating GIFs)
- ✅ GitHub stats cards
- ✅ Streak stats
- ✅ Top languages chart
- ✅ GitHub trophies
- ✅ Contribution activity graph
- ✅ Snake animation (after GitHub Actions runs)
- ✅ All animated dividers and GIFs

## 🐛 Troubleshooting

### GitHub Trophies Not Showing
If trophies don't appear immediately, wait 5-10 minutes. The service may be under heavy load.

Alternative trophy configuration you can try:
```markdown
![trophy](https://github-profile-trophy.vercel.app/?username=Ank0it&theme=dracula&no-frame=true&row=1&column=6)
```

### Snake Animation Not Working

**Common Issues:**
1. **GitHub Actions not enabled** - Follow Step 2 above
2. **Workflow hasn't run yet** - Manually trigger it (Step 3)
3. **Output branch doesn't exist** - The workflow will create it automatically

**Check if workflow ran successfully:**
1. Go to Actions tab
2. Look for a green checkmark next to "Generate Snake Animation"
3. If there's a red X, click it to see the error

### Stats Cards Not Loading

If any stats cards show "404" or don't load:
- Wait 5-10 minutes and refresh
- Clear your browser cache
- These services are free and sometimes have rate limits
